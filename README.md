# Školski IT klub – web stranica

Prezentacijska stranica školskog kluba za programiranje i tehnologiju.
Projektni zadatak iz predmeta Softversko inženjerstvo (4. razred, IT smjer, 2026/2027).

## Sekcije
- Početna (hero + CTA)
- O nama i Članovi
- Projekti (kartice)
- Prijavi se (forma s JavaScript validacijom)
- Responzivan dizajn (mobitel i računalo)

## Tehnologije
HTML5, CSS3, JavaScript (bez biblioteka).

## Kako pokrenuti
Preuzmi repozitorij i otvori `index.html` u pregledniku.
